### 1.2 Типографика

```
Шрифт: Inter (UI), JetBrains Mono (код/токены)

Размеры:
  --text-xs    11px / line-height 16px   Метки, бейджи
  --text-sm    12px / line-height 18px   Вторичный текст
  --text-base  13px / line-height 20px   Основной текст
  --text-md    14px / line-height 22px   Чуть крупнее основного
  --text-lg    16px / line-height 24px   Подзаголовки
  --text-xl    20px / line-height 28px   Заголовки секций
  --text-2xl   24px / line-height 32px   Заголовки страниц
  --text-3xl   32px / line-height 40px   Hero-заголовки

Насыщенность:
  Regular 400 — основной контент
  Medium  500 — навигация, метки
  SemiBold 600 — заголовки, кнопки
  Bold    700 — акценты, счётчики
```

  --radius-sm   4px    Кнопки-теги, бейджи

  --radius-xl   12px   Модальные окна
  --radius-2xl  16px   Пузырь Telegram
  --radius-full 9999px Аватары, пилюли
```

### 1.4 Размеры панелей

```
  Сайдбар:          240px (фиксированный)
  Панель превью:    320px (фиксированная, только в редакторе)
  Панель публикации: 280px (правая, только в редакторе)
  TopBar высота:    48px
  Toolbar редактора: 44px
  Строка списка:    64px (стандарт), 80px (с превью)
  Модальное окно:   480px ширина (S), 640px (M), 800px (L)
```

### 1.5 Иконки

```
Библиотека: Lucide React (stroke-based, consistent weight)
Размеры: 14px (inline), 16px (toolbar), 18px (sidebar), 20px (actions)
Толщина обводки: 1.5px
Цвет по умолчанию: --text-secondary
Цвет hover: --text-primary
Цвет active/акцент: --accent
```

### 1.6 Тени

```
  --shadow-sm:  0 1px 2px rgba(0,0,0,0.3)
  --shadow-md:  0 4px 12px rgba(0,0,0,0.4)
  --shadow-lg:  0 8px 24px rgba(0,0,0,0.5)
  --shadow-modal: 0 20px 60px rgba(0,0,0,0.6)
```

## 11. Микровзаимодействия

### 11.1 Переходы между экранами

```
Тип: fade + slide-in

Уход (250ms):
  opacity: 1 → 0
  transform: translateX(0) → translateX(-8px)

Приход (250ms):
  opacity: 0 → 1
  transform: translateX(8px) → translateX(0)

Easing: cubic-bezier(0.4, 0, 0.2, 1)
```

### 11.2 Автосохранение (индикатор)

```
Состояния TopBar:
  Редактирование:  "●  Изменено"     --text-muted, точка пульсирует
  Сохранение:      "↻  Сохраняем..."  spinner 12px
  Сохранено:       "✓  Сохранено · 14:32"  --success → fade to --text-muted (2с)
  Ошибка:          "✕  Не сохранено"  --danger

Анимация точки пульсации:
  keyframes: opacity 1 → 0.3 → 1, 1.5s ease-in-out infinite
```

### 11.3 Кнопка публикации

```
Idle:     "📤 Опубликовать"   --accent фон
Hover:    --accent-hover, scale(1.01)
Loading:  "⏳ Публикуем..."    spinner, cursor: not-allowed
Success:  "✅ Опубликовано"   --success фон, 2 секунды, затем сброс
Error:    "✕ Ошибка"          --danger фон, 2 секунды, затем сброс

```

### 11.4 Sidebar — активный пункт

```
При клике:
  1. Мгновенно: фон --bg-active, текст --text-primary
  2. 150ms: левая полоска 2px --accent slide-in справа
  3. Иконка: цвет → --accent

При переходе на другой пункт:
  Предыдущий: полоска slide-out, фон → transparent, 150ms
```

### 11.5 Карточки (hover)

```
Default:  border 1px --border-subtle,  shadow none

  scale: 1 → 0.99 (100ms) → 1 (100ms)
```

### 11.6 Drag & Drop медиа в редактор

```
Шаг 1 — файл входит в область окна:
  Весь редактор: overlay rgba(20,20,20,0.7)

  Прогресс-бар на месте будущей миниатюры
  Миниатюра появляется с fade-in (300ms)

## Итоговая сводка

### Ключевые принципы UI

1. **Монохромная основа, один акцент** — вся палитра нейтральная, единственный яркий цвет — Telegram-синий (#2AABEE) для действий и активных состояний.

2. **Контент в центре** — минимальный chrome, максимум пространства для текста. Как Notion: интерфейс исчезает, когда не нужен.

3. **Тёмная тема первична** — разработка ведётся с тёмной темой, светлая — как инверсия CSS-переменных.

4. **Размер шрифта 12–14px** — плотный интерфейс в стиле Obsidian/Telegram Desktop, не раздутый.

5. **Анимации быстрые** — 150–250ms, без задержек. Пользователь не должен ждать интерфейс.

6. **Состояния ошибок inline** — никаких alert-диалогов для ошибок API. Всё показывается в контексте.

7. **Предсказуемая сетка** — 8px базовая единица, отступы кратные 4px.
