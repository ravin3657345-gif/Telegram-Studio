Выносная цитата и подпись автора

  • Новый блок «Выносная цитата» — крупная центрированная цитата с подписью автора, доступен через / и панель блоков

1.8.0 22 июля 2026

собрано и опубликовано в боте

Обход блокировки Telegram в России

  • Если прямое подключение не проходит, приложение автоматически пробует альтернативный путь — через собственный релей-сервер, который просто перенаправляет запрос к Telegram без изменений; без участия пользователя, только когда обычный способ не сработал
  • Оба пути публикации теперь ограничены по времени — раньше могло зависнуть без вести, если ни один способ не пробивался

Редактор на телефоне — управление под палец

  • Панель инструментов на мобильном сжата до частых кнопок + шторка «Ещё» для остального
  • Управление блоком — по тапу вместо наведения мыши (на телефоне это физически не работало)
  • Кнопки «переместить вверх/вниз» вместо перетаскивания пальцем
  • Меню блока и слэш-команда / открываются как шторка снизу экрана вместо мелкого окошка у курсора

Экран и ввод на телефоне

  • Заголовок поста компактнее в горизонтальной (landscape) ориентации
  • Панель публикации и тулбар больше не прячутся под системной клавиатурой
  • Список черновиков — карточки вместо таблицы с колонками, которые давили заголовок на узком экране
  • Фото/видео через тулбар и слэш-команду сразу открывают камеру на телефоне

Уведомления

  • Push-уведомление о результате отложенной публикации (успех/ошибка) — приходит, даже если приложение свёрнуто

Быстрые текстовые заготовки

  • Новая кнопка в тулбаре — сохранённые кусочки текста (призывы к действию, наборы хэштегов, подпись) вставляются в курсор одним кликом, отдельно от полноценных шаблонов постов

Таблицы — навигация стрелками

  • Полностью переработана: вход в таблицу стрелками влево/вправо из соседнего абзаца (раньше вообще не работал)
  • Переход между двумя таблицами подряд — без вставки лишнего пустого абзаца между ними
  • Устранён редкий конфликт со стрелкой вправо в конце ссылки внутри ячейки

Шаблоны и публикация

  • Карточка «Новый шаблон» теперь есть и в галерее готовых примеров, не только среди своих шаблонов
  • Кнопка публикации: рядом с «Запланировать» добавлено «Сохранить как шаблон» прямо из панели публикации

собрано и опубликовано в боте

Плавность редактора

  • Общие motion-токены вместо разрозненных чисел по коду
  • Разъезд блоков при drag — пружинистый easing вместо плоского
  • Лёгкая подсветка текстовых блоков по hover
  • «Призрак» блока при перетаскивании чуть отстаёт от курсора — инерция, как в Craft/Linear
  • FLIP-анимация «оседания» блоков после drop

Картинки и видео

  • Рамка выделения — по размеру медиа, а не во всю ширину редактора
  • Кнопки замены/удаления переехали к углам настоящей рамки
  • Исправлен баг с двойной рамкой (ProseMirror ставил свой контур поверх нового)

Планировщик

  • Ячейка дня — максимум 4 записи, остальные сворачиваются в чип «+N ещё»
  • Высота строки календаря больше не зависит от числа постов на день

Клавиатурная навигация (Word/Excel-стиль)

  • Gap-cursor снова включён — курсор не «упирается» рядом с картинкой
  • Стрелки на границе абзаца проходят мимо картинок/видео/опросов, не выделяя блок целиком
  • Ctrl+Home/Ctrl+End — прыжок в начало/конец поста
  • ↑/↓/Enter/Delete — навигация по спискам (Черновики, Шаблоны, История, Каналы, Боты)
