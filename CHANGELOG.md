# Журнал изменений — Telegram Studio

Одна запись на каждую сборку, которая ушла в бот (не на каждый коммит). Новые записи — сверху.

Живая красивая версия этого журнала: см. память `project_changelog_journal` (URL артефакта) — там же обновляется после каждого релиза.

---

## 1.7.8 — 2026-07-17

**Плавность редактора**
- Общие motion-токены (длительности/кривые) вместо разрозненных чисел по коду
- Разъезд блоков при drag — пружинистый easing вместо плоского
- Лёгкая подсветка текстовых блоков по hover
- «Призрак» блока при перетаскивании чуть отстаёт от курсора (инерция, как в Craft/Linear)
- FLIP-анимация «оседания» блоков после drop

**Картинки и видео**
- Рамка выделения — по размеру медиа, а не во всю ширину редактора
- Кнопки замены/удаления и плашка коллажа переехали к углам настоящей рамки
- Исправлен баг с двойной рамкой (ProseMirror ставил свой контур поверх нового)

**Планировщик**
- Ячейка дня — максимум 4 записи, остальные сворачиваются в чип «+N ещё» с диалогом полного списка
- Высота строки календаря больше не зависит от числа постов в один день

**Клавиатурная навигация (Word/Excel-стиль)**
- Gap-cursor снова включён — курсор не «упирается» рядом с картинкой
- Стрелки на границе абзаца проходят мимо картинок/видео/опросов и т.д., не выделяя блок целиком
- `Ctrl+Home`/`Ctrl+End` — прыжок в начало/конец поста
- `↑`/`↓`/`Enter`/`Delete` — навигация по спискам (Черновики, Шаблоны, История, Каналы, Боты)

Проверка: `tsc` + `vitest` (161/161) чисто. Собрано (`tauri build`), опубликовано в Supabase Storage, `bot_config.latest_installer_version` → `1.7.8`.

## 1.7.7 — 2026-07-16

- Декодирование реальной ошибки автосохранения вместо немой иконки (лимит вложений и т.п.)

- Кнопка замены картинки в редакторе + компактная плашка вместо одинокого крестика
- Drag-ghost блоков теперь режется и по ширине, не только по высоте
- Убраны «Скачать»/«Скорость воспроизведения» из плеера аудио-блока
- sales-bot: поддержка нескольких администраторов (`admin_chat_id` через запятую) + меню админ-команд зарегистрировано для обоих

Собрано, опубликовано в Supabase Storage, `bot_config.latest_installer_version` → `1.7.7`.
