# Журнал изменений — Telegram Studio

Одна запись на каждую сборку, которая ушла в бот (не на каждый коммит). Новые записи — сверху.

Живая красивая версия этого журнала: см. память `project_changelog_journal` (URL артефакта) — там же обновляется после каждого релиза.

## 1.8.3 — 2026-07-23

**Выносная цитата и подпись автора (Bot API 10.2, только Rich-режим)**
- Новый блок «Выносная цитата» — крупная центрированная цитата с подписью автора, доступен через `/` и панель блоков
- У обычной цитаты появилось поле «Автор» — подпись показывается под текстом цитаты
- Оба варианта вне Rich-режима блокируются с предупреждением и ссылкой «Переключиться на Rich»

**Публикация — исправления**
- Rich-пост без вложенных фото/видео переставал публиковаться («relay: no files given») — починено
- Встроенный пример-шаблон «Витрина блоков» терял картинки при повторном использовании — исправлена ошибка в базе (одна и та же картинка привязывалась к чужому черновику)

Проверка: `tsc` + `vitest` (192/192) чисто.

## 1.8.0 — 2026-07-22

**Обход блокировки Telegram в России**
- Если прямое подключение не проходит (блокировка), приложение автоматически пробует альтернативный путь — через собственный релей-сервер, который просто перенаправляет запрос к Telegram без изменений; без участия пользователя, только когда обычный способ не сработал
- Оба пути публикации теперь ограничены по времени (было — могло зависнуть без вести, если ни один способ не пробивался)

**Редактор на телефоне — управление под палец**
- Панель инструментов на мобильном сжата до частых кнопок + шторка «Ещё» для остального
- Управление блоком — по тапу вместо наведения мыши (на телефоне это физически не работало)
- Кнопки «переместить вверх/вниз» вместо перетаскивания пальцем
- Меню блока и слэш-команда `/` открываются как шторка снизу экрана вместо мелкого окошка у курсора

**Экран и ввод на телефоне**
- Заголовок поста компактнее в горизонтальной (landscape) ориентации
- Панель публикации и тулбар больше не прячутся под системной клавиатурой
- Список черновиков — карточки вместо таблицы с колонками, которые давили заголовок на узком экране
- Фото/видео через тулбар и слэш-команду сразу открывают камеру на телефоне

**Уведомления**
- Push-уведомление о результате отложенной публикации (успех/ошибка) — приходит, даже если приложение свёрнуто

**Быстрые текстовые заготовки**
- Новая кнопка в тулбаре — сохранённые кусочки текста (призывы к действию, наборы хэштегов, подпись) вставляются в курсор одним кликом, отдельно от полноценных шаблонов постов

**Таблицы — навигация стрелками**
- Полностью переработана: вход в таблицу стрелками влево/вправо из соседнего абзаца (раньше вообще не работал), переход между двумя таблицами подряд без вставки лишнего пустого абзаца, устранён редкий конфликт со стрелкой вправо в конце ссылки внутри ячейки

**Шаблоны и публикация**
- Карточка «Новый шаблон» теперь есть и в галерее готовых примеров, не только среди своих шаблонов
- Кнопка публикации: рядом с «Запланировать» добавлено «Сохранить как шаблон» прямо из панели публикации

Проверка: `tsc` + `vitest` (189/189) + `cargo check` чисто. Desktop-сборка (`tauri build`) — первая фактическая поставка версии 1.8.0 (номер уже был поднят раньше, но не собирался и не публиковался).

## 1.7.8 — 2026-07-17

**Плавность редактора**
- Общие motion-токены (длительности/кривые) вместо разрозненных чисел по коду
- Разъезд блоков при drag — пружинистый easing вместо плоского
- Лёгкая подсветка текстовых блоков по hover
- «Призрак» блока при перетаскивании чуть отстаёт от курсора (инерция, как в Craft/Linear)
- FLIP-анимация «оседания» блоков после drop

**Картинки и видео**
- Рамка выделения — по размеру медиа, а не во всю ширину редактора
- Кнопки замены/удаления и плашка коллажа переехали к углам настоящей рамки
- Исправлен баг с двойной рамкой (ProseMirror ставил свой контур поверх нового)

**Планировщик**
- Ячейка дня — максимум 4 записи, остальные сворачиваются в чип «+N ещё» с диалогом полного списка
- Высота строки календаря больше не зависит от числа постов в один день

**Клавиатурная навигация (Word/Excel-стиль)**
- Gap-cursor снова включён — курсор не «упирается» рядом с картинкой
- Стрелки на границе абзаца проходят мимо картинок/видео/опросов и т.д., не выделяя блок целиком
- `Ctrl+Home`/`Ctrl+End` — прыжок в начало/конец поста
- `↑`/`↓`/`Enter`/`Delete` — навигация по спискам (Черновики, Шаблоны, История, Каналы, Боты)

Проверка: `tsc` + `vitest` (161/161) чисто. Собрано (`tauri build`), опубликовано в Supabase Storage, `bot_config.latest_installer_version` → `1.7.8`.
