# Инструкция по скриншотам для документации

Здесь хранятся скриншоты для файла `docs/README.md`.

## Нужные скриншоты (18 штук)

Запустите приложение (`npm run tauri dev`) и сделайте следующие скриншоты:

| Имя файла | Что снимать |
|-----------|-------------|
| `01_main_editor.png` | Главный экран — редактор с каким-нибудь текстом |
| `02_installer.png` | Окно установщика MSI (можно пропустить) |
| `03_botfather.png` | Скриншот Telegram — диалог с BotFather, получение токена |
| `04_channel_admin.png` | Настройки канала → Администраторы |
| `05_userinfobot.png` | Ответ @userinfobot с ID канала |
| `06_add_channel.png` | Форма добавления канала в приложении |
| `07_full_interface.png` | Полный интерфейс с боковым меню, редактором и предпросмотром |
| `08_empty_editor.png` | Чистый редактор без текста |
| `09_toolbar.png` | Панель инструментов крупным планом |
| `10_slash_menu.png` | Меню команды "/" (нажмите / в редакторе) |
| `11_context_menu.png` | Контекстное меню (правая кнопка в редакторе) |
| `12_bubble_menu.png` | Всплывающая панель форматирования (выделите текст) |
| `13_color_picker.png` | Палитра цветов (нажмите A в bubble menu) |
| `14_drag_handle.png` | Иконка перетаскивания слева от блока |
| `15_image_block.png` | Редактор с вставленным изображением |
| `16_html_panel.png` | Редактор с открытой HTML-панелью справа |
| `17_char_counter.png` | Нижняя строка с счётчиком символов |
| `18_preview.png` | Правая панель предпросмотра с постом |
| `19_publish_panel.png` | Панель публикации с выбором канала |
| `20_schedule.png` | Диалог выбора даты публикации |
| `21_drafts.png` | Список черновиков |
| `22_settings.png` | Страница настроек |
| `23_telegraph.png` | Раздел Telegraph в настройках |

## Как вставить в документацию

В `docs/README.md` найдите метку вида:

```
`[СКРИНШОТ: описание]`
```

Замените её на:

```markdown
![описание](screenshots/имя_файла.png)
```

Пример:

```markdown
![главный экран редактора](screenshots/01_main_editor.png)
```
